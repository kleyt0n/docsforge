# Rust API

The reference for the companion crate in `rust/` is generated by
[rustdoc](https://doc.rust-lang.org/rustdoc/) from the `///` doc comments in
the source — the same text you get from `cargo doc --open`. Because it is
generated, it always matches the code.

An [MkDocs hook](https://www.mkdocs.org/user-guide/configuration/#hooks)
(`scripts/rustdoc_hook.py`) runs `cargo doc --no-deps` on every site build and
folds the output into the site under `rust/` — in `mkdocs serve`, in
`mkdocs build`, and in CI alike.

[Open the Rust API reference](../rust/docsforge/index.html){ .md-button .md-button--primary }

!!! note "Editing the crate while serving"
    `mkdocs serve` watches the docs, not the crate, so changes to `rust/src/`
    do not trigger a rebuild on their own. Touch any docs page (or restart the
    server) and the hook regenerates the rustdoc on the next build.

## Testing the crate

Doctests in the doc comments run as part of the suite, so every example in
the reference is verified on each commit — the Rust counterpart of pytest's
`--doctest-modules`:

```bash
cargo test --manifest-path rust/Cargo.toml
```
